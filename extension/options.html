Shortcuts and optional desktop keys

Browser shortcuts

Choose combinations that are free in your browser. Chrome, Edge and Brave manage these assignments.

A missing assignment can mean a conflict or an intentionally cleared shortcut. Test it on a normal webpage.

Single keys from desktop

Use Home, Page Up, F8 or another spare key configured in SnipyNest desktop. No vendor software or keyboard firmware changes are needed.

  1. In desktop Settings, choose your browser and set up the browser connection.
  2. Enable the connection here, then assign keys in desktop Settings.

This optional mode needs native messaging to the local desktop helper and capture access to all sites, so a desktop key can capture a newly opened page. It captures only when you trigger an action. Standard popup captures and browser shortcuts do not need this extra access.

About captures

Visible PNG captures the current browser viewport. Full PNG and PDF scroll through a bounded page. PDF also copies a PNG. The desktop app must be running with monitoring enabled to collect it.

Protected pages, browser settings and unsupported scrolling pages require Windows snipping. No capture is uploaded by SnipyNest.
