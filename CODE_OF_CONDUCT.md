# Community conduct

Treat contributors respectfully. Discuss code and evidence, not personal attacks. Harassment, discrimination, threats, doxxing and unsolicited advertising are not welcome. Protect other people's private information.

Maintainers may edit or remove harmful content, close disruptive discussions, and restrict participation. Report conduct concerns privately through the maintainer's available GitHub contact; if no private contact is available, request one without publishing sensitive details. For threats or platform abuse, use GitHub's Report abuse feature.

These expectations apply to issues, pull requests, reviews and project discussions. Disagreement about design is welcome when it is specific and respectful.
