# Security reporting

Please report vulnerabilities privately using the repository's Security tab → Report a vulnerability:
https://github.com/Basantbhat162/snipynest/security/advisories/new

If private reporting is unavailable, open an issue requesting a private contact without exploit details, secrets, clipboard contents or personal data. Do not post sensitive reports in public issues.

Include the affected version, a minimal synthetic reproduction, impact and suggested mitigation if known. Maintainers will assess reports as time allows; there is no guaranteed response time or security support contract. The current 1.3.0 build is a preview, with outstanding live acceptance tests.

Clipboard history may contain sensitive data. Read PRIVACY.md before using SnipyNest on shared computers.
