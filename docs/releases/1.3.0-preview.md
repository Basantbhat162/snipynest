# SnipyNest 1.3.0 — Windows desktop public preview

## Download and install

**[Download Windows installer (.exe)](https://github.com/Basantbhat162/snipynest/releases/download/v1.3.0-preview/SnipyNest_1.3.0_x64-setup.exe)**

For Windows 10/11 x64 desktop PCs. Download the `.exe`, run setup, then launch SnipyNest. Press **Ctrl+Shift+V** to open history. Requires Microsoft Edge WebView2 Runtime. No macOS, Linux, mobile or native ARM64 installer is provided.

The installer is unsigned. Verify its [SHA-256 checksum](https://github.com/Basantbhat162/snipynest/releases/download/v1.3.0-preview/SHA256SUMS-1.3.0.txt) with PowerShell `Get-FileHash <downloaded-file> -Algorithm SHA256` before deciding whether to run it. Do not disable antivirus protections.

## Optional browser extension — separate download

**[Download Companion extension (.zip)](https://github.com/Basantbhat162/snipynest/releases/download/v1.3.0-preview/SnipyNest-Companion-1.3.0.zip)**

1. Extract the ZIP into a permanent folder using **Extract All**.
2. Open `brave://extensions`, `chrome://extensions`, or `edge://extensions`.
3. Enable **Developer mode** and click **Load unpacked**.
4. Select the extracted folder containing `manifest.json`, then pin SnipyNest Companion.
5. Open a normal webpage and click **Capture**, or use **Alt+Shift+S**. Keep the tab active while capture runs. Keep the desktop app running with monitoring enabled to collect copied images.

Desktop setup does not install or update the extension. For extension updates, extract the new ZIP, reload the extension and refresh the webpage. [Full usage and troubleshooting guide](https://github.com/Basantbhat162/snipynest/blob/main/extension/README.md).

## Which asset do I need?

- `SnipyNest_1.3.0_x64-setup.exe`: Windows desktop app setup.
- `SnipyNest-Companion-1.3.0.zip`: optional browser extension, loaded unpacked.
- `SHA256SUMS-1.3.0.txt`: download verification hashes.
- License and notice files: redistribution terms.
- GitHub’s **Source code** archives: developer files; these are not app installers.

## Preview status and verification

61 frontend/Companion tests and 24 Rust tests passed; three live clipboard tests were intentionally skipped. Windows CI, TypeScript checks and optimized installer build passed. Both published packages were downloaded and matched their local SHA-256 hashes. The executable was built with local-path remapping and scanned for known local username/user-directory paths.

Live browser, native gestures and installer upgrade acceptance remain incomplete. This is a public preview, not a stable or all-website-certified release. Custom scrolling, infinite feeds and animation-heavy pages may need Visible area or Scrolling panel mode. Read the [known limitations](https://github.com/Basantbhat162/snipynest/blob/main/docs/VERIFICATION.md).

History is local and not encrypted. Read [Privacy](https://github.com/Basantbhat162/snipynest/blob/main/PRIVACY.md). Report problems using [Issues](https://github.com/Basantbhat162/snipynest/issues/new/choose); never attach private clipboard data. Contributions are welcome through reviewed pull requests.
