# SnipyNest 1.3.1 — Windows clipboard and capture reliability (Preview)

Download **SnipyNest_1.3.1_x64-setup.exe** for Windows 10/11 x64. The optional **SnipyNest-Companion-1.3.1.zip** is a separate browser extension, not an installer. Source-code archives are for developers.

## Changes

- Shortcut capture stays on the webpage. If background copying is rejected, it tries the focused captured page; it no longer opens a result tab automatically.
- Restored recent images update history quietly, without repeating capture sound or Pad alerts. Explicit Windows snips can still notify for identical pixels.
- Clipboard monitoring coalesces duplicate notifications, retries temporarily busy snapshots and checks for missed notifications. Image conversion no longer holds the global clipboard lock or runs on the shortcut thread.
- Pad arrivals wait for native dragging/movement to finish instead of being discarded. Native visibility controls drag presentation.

## Install or update

1. Download the Windows `.exe`, verify its SHA-256 using the accompanying checksum file, quit the running app from its tray menu, then install. This preview is unsigned. Do not disable antivirus protections.
2. Launch SnipyNest and use Ctrl+Shift+V for history. Existing legacy OmniCopy data paths are retained. Back up important history before upgrading.
3. For the extension, extract the Companion ZIP into a permanent folder. Open brave://extensions, chrome://extensions or edge://extensions, enable Developer mode and choose Load unpacked; select the folder containing manifest.json. For an existing unpacked installation, update that folder and Reload the extension, then refresh target pages.
4. Use Alt+Shift+S on a normal webpage. If the toolbar shows PNG, open the extension and use Copy image or Save PNG. Desktop installation does not update the extension.

## Verification and known limits

Automated results are recorded in docs/VERIFICATION.md at this tag. Browser-adapter tests use simulated APIs. Actual Brave clipboard permission behavior, Wispr interaction, multi-hour Windows reliability, mixed-DPI gestures and installed upgrade remain unverified. This is a preview, not a certified stable release.

Automatic focused-page transfer is capped at 16 MiB; larger results retain popup Copy/Save up to the existing 64 MiB result limit. Repeated non-Windows-snip images among 64 recent fingerprints are intentionally quiet. Rapid clipboard overwrites can still be missed. Protected browser pages require Windows snipping; arbitrary animation/custom scroll engines are not guaranteed.
