# Capture sound

The public capture.wav is an original synthesized cue generated by scripts/generate-capture-sound.py. It uses mathematical oscillators and envelopes, without recordings or third-party samples. The generator and output are covered by the project MIT license. Format: 48 kHz mono, 16-bit PCM, 0.54 seconds.

An earlier local candidate used a supplied audio asset whose redistribution terms were not established. That asset is excluded from the public repository and public installer.
